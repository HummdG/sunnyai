Plan §9 is a threat model rather than a table of deliverables, so it has no rows
here: each threat is answered by a decision entry where it is closed — cross-tenant

Status is exactly one of `Done`, `Partial`, `Not started`, `Blocked`, `Not applicable`.
`Partial` means some of the requirement is real and some is not; the note says which.
Where a requirement sits behind a refusal or a mock, it is at best `Partial` and the
note names the real and the unreal part. Evidence is a path, a test name, or a command.
