# Bundled fonts

Used by the quotation PDF (`apps/api/src/proposal/layout.ts`). Both families are
licensed under the SIL Open Font License 1.1 (see `OFL-InterTight.txt` and
`OFL-IBMPlexMono.txt`).

## Sources

`https://fonts.googleapis.com/css2?family=Inter+Tight:wght@300;400;600;800`
requested with a non-browser User-Agent so it returns TrueType):
