# Sample house

`house.spec.json` is the roof the Studio preview and the sample proposal PDF
draw, marked "Sample" on the plan, so installers see a real roof plan while
they set up their quotation.

- Address: 20 Forthlin Road, Liverpool L18 9TN (OSM `way/516125064`), the
  `uk-forthlin-road` entry in `fixtures/sunscan/test-addresses.json`. Public
  test data: a National Trust property, not a customer.
- Source: a SunScan assessment generated in development on 2026-10-12,
  `.data-dev/sunscan-artefacts/t_demo0001/ss_731c1eda974247899a91/spec.json`,
  copied unchanged apart from formatting.
- Roof: a mid-terrace gable. The south-facing slope (azimuth 162 degrees,
  pitch 42 degrees) takes up to 12 panels; the north slope takes none by
  default.
