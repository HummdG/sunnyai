Sunny — animation lab

Every sequence in the build, driven by the real engine. This page exists to answer the one question a unit test cannot: does the character still look like the reference artwork when it moves? What is on screen here is the same frame(t) call the widget makes, so nothing here is a re-implementation.

The character

Play tic-tac-toe

A real game against Sunny — the rules live in @sunny/games and the board is driven by them rather than by a copy of them. She shows off when a game starts, thinks on her turn, and takes a moment when it ends. She is a heuristic rather than a solver: a perfect opponent can never be beaten, and a game you cannot win is not a game.

The arcade

A08 is the plan's arcade row, and its fourth word is lazy-loaded: the rules live in @sunny/games like tic-tac-toe's, but the game itself is a separate bundle (/arcade.js) that this page fetches only when the button is pressed. A test watches the network to prove it, because "lazy-loaded" is a claim about bytes rather than about intentions.

Flagship moments

Each button asks the scheduler for a moment, not a variant, and the tenant's intensity setting picks the strength. That is what stops an intensity setting from silently deleting a behaviour.

The catalogue

Every moment Sunny has, named for a person rather than for the engine. Play asks the scheduler for the moment — the same call the widget makes — and the card lights up while it is the one on screen, so what the catalogue claims and what the engine draws can be compared by eye. A dashed card is a moment the engine never asks for by itself: it is implemented and tested, and reaching it is a matter of wiring — an event or a pointer gesture nothing forwards yet.

Every sequence

Greyed cards are sequences above the currently selected intensity. They are dimmed rather than hidden so that an intensity can never quietly remove a behaviour from the build without someone noticing here.

Theme

The ink and highlight are deliberately constant across presets: a tenant may choose the body colour, but the face has to stay legible on whatever they choose.
